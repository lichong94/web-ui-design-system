## 定位

名为 **Simple Light** 的免费落地页模板，基于 TailwindCSS 编写，完整使用 React / Next.js 实现。目标是为 SaaS 产品、在线服务等落地页提供基础组件与整套页面骨架。2025-02-04 更新已支持 Tailwind v4。

## 核心内容（来自官方 README）

- 提供 SaaS、在线服务类落地页所需的基础组件组合。
- 基于 `create-next-app` 引导的 Next.js 项目，使用 App Router 与 React Server Components。
- 使用 `next/font` 自动优化并加载 Inter 字体。
- 提供免费 Figma 设计文件（Figma Community）。
- 历史版本：v1.3.3（Tailwind CSS + React + Vite）在 Releases 标签中提供。

## 本地运行（README 命令）

```bash
npm run dev
# 或
yarn dev
# 或
pnpm dev
```

浏览器打开 http://localhost:3000 查看；主要编辑入口为 `app/page.tsx`，文件改动后页面自动更新。

## 适用场景

- 公司官网、产品介绍页、活动/营销落地页。
- 需要简洁、现代、改文案和图片即可上线的单页站点。
- 同时需要 Next.js 或 Vite 两套构建方式时可对应取用。

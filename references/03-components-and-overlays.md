# 03 组件选型与浮层决策统一规范

本篇统一各端的组件选用判据与浮层决策树。核心原则：缺的从来不是“能用什么”，而是“不该用什么”。先按量级、频次、时长、重要性、语义与结构前提排除错误选项，再落具体组件。视觉原子法则见 [01-foundations-and-tokens.md](./01-foundations-and-tokens.md)，骨架见 [02-layout-patterns.md](./02-layout-patterns.md)。

## 一、六大否定判据

1. **量级不匹配**：弹窗需垂直滚动超 1.5 屏或含复杂子向导 → 改抽屉/整页；抽屉仅一两句说明 → 改对话框；下拉选项 <5 个 → 单选平铺；单选 >6 个 → 下拉；只有两个布尔选项 → 单选或开关，严禁下拉。
2. **频次不匹配**：每天十几次的单项确认 → 气泡确认，避免全屏弹窗反复阻断；频繁填写的地址/类别 → 带联想记忆输入组件。
3. **时长阈值**：<1 秒严禁骨架屏（强闪烁）；1–3 秒按钮内轻量 Loading，严禁整页大进度条；>10 秒必须展示进度百分比、预计剩余时间，并提供取消与后台运行出口。
4. **重要性错配**：完成任务所需的关键提示/错误严禁藏在 Tooltip/Popover 气泡内；字段格式错误在字段正下方红字提示，严禁全局 Alert/模态弹窗；删除/清空/财产变更严禁轻飘飘气泡框，必须升级模态对话框。
5. **语义错位**：原地改状态用 Button，跨路由/外链用 Link；子系统主导航用 SideNav，单模块内容切换用 Tabs；改动立即生效用 Switch，随整表提交用 Checkbox。
6. **结构前提补充**：Tabs 前提是内容可清晰分类、互不依赖、无需横向对比；需反复比对两组数据时取消 Tabs 改垂直平铺。骨架屏前提是布局结构高度固定；瀑布流/长文本等高度动态场景禁用骨架屏，改局部 Spin。已知强记忆字段（身份证、生日、税号）优先 OCR/剪贴板解析，不让用户逐项手敲。

## 二、输入与选择控件选型表

| 场景 | 正确选型 | 严禁选型 | 否定判据 |
| --- | --- | --- | --- |
| 布尔状态立即生效 | Switch 开关 | Checkbox / Select | 开关代表电路接通，改后立即触发底层状态变更，无需保存 |
| 布尔选项提交生效 | Checkbox 复选框 | Switch | 需随整表提交才生效的字段，避免误导以为已即时生效 |
| 2–4 个互斥选项 | Radio 单选平铺 | Select 下拉 | 选项极少时下拉需点开两步，平铺一眼扫过一次点击完成 |
| 5+ 个互斥选项 | Select 下拉选择器 | Radio 单选 | 选项过多挤占垂直/水平空间，视觉噪音大 |
| 多项勾选 | Checkbox 组合 | Multi-Select | <6 项优先平铺复选；极多才用多选下拉标签栏 |
| 选项超 10 个 | 带搜索的 Select | 普通 Select | 必须支持拼音/英文字符模糊检索 |

### 输入键盘与字段类型（触屏/H5）

严禁所有输入项无脑 `type="text"`：

| 业务场景 | HTML5 配置 | 键盘效果 | 细节增益 |
| --- | --- | --- | --- |
| 手机号码 | `type="tel"` `inputmode="tel"` | 纯数字九宫格（带 + * #） | 单手极速输入，支持粘贴 |
| 短信验证码 | `inputmode="numeric"` `autocomplete="one-time-code"` | 纯数字键盘 | 支持系统短信验证码一键填充 |
| 金额/纯数值 | `inputmode="decimal"` | 带小数点紧凑数字键盘 | 防误触字母特殊字符 |
| 电子邮箱 | `type="email"` `inputmode="email"` | 含 @ 和 . 独立按键 | 免翻标点面板找 @ |
| 搜索框 | `type="search"` | 右下角主键变“搜索” | 监听 Enter 直接触发搜索 |
| 安全密码 | `type="password"` | 密码安全键盘，遮蔽防录屏 | 右侧配“眼睛”切换显隐 |

## 三、浮层决策树

先分清两组概念：**模态（Modal）**是界面层级问题（是否禁止操作遮罩以下部分）；**阻断（Blocking）**是任务流程问题（是否打断沉浸心流）。上了模态弹窗不等于打扰了用户。

```text
用户触发的操作
├── 轻量动作 / 确认
│   ├── 操作可逆、可反悔？
│   │   └── 是 → 不弹确认框，直接执行 + 底部 Snackbar 带「撤销」后悔药
│   ├── 高危 / 不可逆？
│   │   ├── 是 → 影响大？大 → AlertDialog 锁死阻断；小 → 气泡确认
│   │   └── 否 → 低频简短操作？→ 气泡确认
│   └── 字段格式错误 → 行内 Inline Alert 红字紧跟输入框（不弹 Toast、不自动消失）
├── 信息录入 / 查看
│   ├── 短小/聚焦 → 宽幅图片/视频？→ Lightbox 灯箱全屏预览
│   ├── 深层/长表单/需对比 → 保留列表上下文？是 → 抽屉；否 → 独立整页
│   └── 触屏窄屏 → 半屏表单/选项/筛选？→ Bottom Sheet；单维度操作分流？→ ActionSheet
└── 新功能/首次使用引导 → Tour 聚光灯气泡分步漫游
```

| 组件 | 核心适用场景 | 避免使用（AvoidWhen） |
| --- | --- | --- |
| 气泡确认 Popconfirm | 高频、轻量、原地单项确认（删单行、重试单次任务），鼠标动线最短 | 大额资金、批量删除、系统级权限重置等高危操作（阻力不够） |
| 模态对话框 Modal | 短确认、重要公告、聚焦型极轻量录入（<5 字段）、宽幅图表预览；点遮罩/Esc 可关闭 | 长表单、深层操作、需频繁参考原底表比对的任务；不可逆高危动作（应升级 AlertDialog） |
| 侧边抽屉 Drawer | 复杂对象详情、多字段轻编辑、复杂筛选，且必须保留列表背景上下文 | 完整支付流程、多步骤大型向导、需独立 URL 分享的单据 |
| 底部抽屉 Bottom Sheet | 窄屏下评论区、SKU 选择、多维筛选、地址选择、购物车；自带阻尼手势分档吸附 | 宽屏深层长流程；需独立 URL 协同分享的单据 |
| ActionSheet | 窄屏单维度操作分流（拍照/相册/取消、分享渠道、切换账号） | 承载 >2 个输入框或长图文详情 |
| Snackbar 撤销快写条 | 可逆操作执行后底部轻量反馈，右侧必带可点击「撤销」；成本最低的后悔药容器 | 不可逆高危操作（不能靠撤销兜底）；需要承载长说明或多个操作 |
| AlertDialog 警报阻断弹窗 | 删库、注销账号、巨额扣款等彻底不可逆高危动作；锁死遮罩、禁用 Esc，强制看清损失后亲手确认 | 普通可取消的公告、轻量录入；可撤销的常规删除（应走 Snackbar 撤销） |
| Tour 漫游式引导 | 新功能上线、首次使用；背景挖空聚光灯 + 气泡分步带点，含步骤进度 | 日常高频操作路径；强制打断正在进行的任务 |
| Inline Alert 行内校验 | 表单字段错误紧跟输入框下方红字；改对后才消失 | 用 Toast 几秒自动消失；全局 Alert 打断整表提交 |
| Lightbox 媒体灯箱 | 点开缩略图后全黑背景看大图/视频，支持滚轮/双指缩放与左右切换 | 多图复杂排版、需要保留页面上下文的图文混排 |
| 独立新页面 Page | >10 字段大型表单、分步向导、沉浸式创作、需独立 URL 协同分享 | 查看一两条属性、几秒完成的修改（丢失列表筛选与翻页状态） |

### 列表进详情四大判据

| 方式 | 何时使用 | 严禁反模式 |
| --- | --- | --- |
| 同页内联展开 Expand Row | 详情极短（1–3 行，不超半屏），查看频率极高 | 展开后两屏高，把后方数据行挤出视野 |
| 侧边抽屉 Drawer | 详情超一屏，需对照其他行判断或轻编辑 | 详情需发同事协同却做成抽屉，无可分享 URL |
| 双栏布局（左列表/右详情） | 连续处理几十条工单/审批，条目间极速切换 | 每条都跳新整页，返回后滚动位置与筛选全丢 |
| 独立详情页 Page | 信息量巨大、多复杂 Tabs、需对外分享单据 | 查看一两个电话也要整页刷新跳转 |

## 四、浮层尺寸与高危阻力设计

### 量化尺寸标准

- **Modal 三档宽度**：小 400px（轻量二次确认/密码验证）；中 520px（最通用，4–6 字段表单）；大 720–800px（复合关联、穿梭选择、复杂预览）。高度随内容自适应，严禁超出一屏；超长内容内部滚动，固定顶部标题与底部操作栏；加载中与加载完成高度一致，防界面跳动。
- **Drawer 三档宽度**：窄 400px（详情浏览、轻量配置、高级筛选）；中 600px（带 Tabs 标准详情、审计记录）；宽 800–900px（复杂配置、子表格、双列轻编辑）。
- **底部抽屉三分屏高度**：统一按屏幕高度 **30% / 60% / 83%** 三档取值，不写死像素。30% 单选选择器/支付方式二选一/短提示；60% 最通用（中等筛选、商品摘要、评论区）；83% 多步骤填写、SKU 选择、复杂树形选择（顶部留约 17% 原生背景露底，支持点击快速关闭）。顶部 36×4pt 拖拽手柄。
- **Bottom Sheet 阻尼手势分档吸附**：与侧边 Drawer 最大区别是自带阻尼手势、可分档吸附。三档状态：刚露头为**折叠态**，拉到中间为**半开态**，向上猛一划直达**全屏态**；松手按当前速度与位置吸附到最近档位，边界带弹簧回弹。窄屏高频浮层一律从底部升起，适配拇指自然舒适区，不要从侧边硬划面板。

### 高危与不可逆操作阻力设计

- 可逆操作去掉阻力（提供撤销 Undo，优先走 Snackbar）；不可逆操作主动增加摩擦力。
- **普通 Modal 与 AlertDialog 严格区分**：

| 维度 | 普通 Modal | AlertDialog 警报阻断弹窗 |
| --- | --- | --- |
| 适用 | 可取消的公告、轻量录入、一般确认 | 删库、注销账号、巨额扣款等彻底不可逆动作 |
| 遮罩点击 | 点外部黑背景可关闭 | **强行锁死背景遮罩，禁止点遮罩关闭** |
| Esc 键 | 可按 Esc 安全取消 | **禁用 Esc 关闭**，逼用户亲手点按钮 |
| 损失呈现 | 一般说明 | 必须看清损失金额/影响人数/是否不可撤销后再操作 |
| 按钮文案 | 中性取消/确定 | 动词+宾语明确后果（“确认注销”“彻底删除 (3 项)”），禁用模糊“确定” |

- 标题中立陈述事实与对象（“确定解散「技术研发部」群组？”），禁用“您确定吗？”“温馨提示”等含糊口号；描述区列明影响人数、关联数据是否丢失、是否不可撤销；主按钮用动宾结构并声明后果（“彻底删除 (3 项)”“确认扣款 ¥1,200”）。
- 技术门禁：含录入表单或高危确认的弹窗 **严禁开启点击遮罩关闭（maskClosable=false）**；AlertDialog 打开后键盘焦点锁定弹窗内、禁用 Esc；危险主按钮严禁默认聚焦；确认后按钮 Loading 并禁用取消与关闭键，防重复扣费/破坏。

### 浮层原点与 Tooltip 时机

- **Popover 从触发点缩放**：锚定具体触发元素的 Popover / Dropdown / 选择器，`transform-origin` 指向触发位置（可用 `var(--transform-origin)`），从触发点方向展开，而非默认从中心缩放。**例外：Modal 居中弹出，原点保持 `center`**，因其不锚定某个触发元素。
- **Tooltip 首条延迟、相邻即开**：第一条 Tooltip 出现前设短暂延迟，避免悬停误触即弹出；同一工具条内已有一个 Tooltip 展开后，滑向相邻 Tooltip 应即时出现、跳过延迟与动画，让整条工具条显得跟手。
- **可中断浮层用 transition**：高频增删的浮层（Toast、开关态切换）用 CSS `transition`，可在中途被新动作重定向；`@keyframes` 动画被中断会从零重启，不适合高频触发的动态 UI（详见 04 篇第十一节）。

### 窄屏浮层滚动与穿透

- 抽屉内部长列表滚到最顶（scrollTop===0）继续下拉，判定为关闭抽屉意图，跟随位移下滑出视口；scrollTop>0 时优先内部回滚，不误触发关闭。
- 浮层关闭淡出动画 200–300ms 期间，遮罩 `pointer-events: none` 阻断点击穿透。
- 表单录入类底部抽屉/对话框 `maskClosable={false}`，退出必须点取消/关闭按钮。

## 五、轻提示、撤销与引导组件

### 1. 轻提示分级：Toast / Message / Notification / Snackbar

| 组件 | 形态与时长 | 可操作性 | 适用场景 | 禁忌 |
| --- | --- | --- | --- | --- |
| Toast | 屏幕下方/中央短暂浮现，1.5–2.5s 自动淡出 | 无可点击按钮 | 纯结果反馈（已复制、已收藏），不阻断底层 | 承载可操作项；放关键错误或必填校验 |
| Message | 页面顶部/内侧条状提示 | 可带单条关闭 | 轻量成功/警告/信息通知 | 替代高危确认 |
| Notification | 右上角常驻通知列表 | 可跳转、可处理 | 后台异步结果、系统级消息 | 抢占当前操作视线 |
| Snackbar 撤销快写条 | 底部黑/深色短条，紧贴内容边缘 | **右侧必带可点击「撤销」按钮** | 可逆操作执行后的后悔药（删邮件、撤回消息、取消收藏） | 不可逆动作；长条塞满说明文字与多个操作 |

**Snackbar 铁律**：能撤销就别弹确认框打扰用户。删除、归档、取消订阅等可逆动作直接执行，底部弹出 Snackbar 写明“已删除”，右侧「撤销」一键复原；这是给用户发后悔药成本最低的容器。撤销操作必须真实回滚数据，并在撤销后给出二次反馈。

### 2. ActionSheet 底部动作面板规约

- 窄屏单维度操作分流（更换头像：拍照/从相册选择；分享渠道；切换账号），从底部升起一排扁平按钮，单手拇指盲点可达；
- **最底部必定有一行独立分组的「取消」按钮**，与上方动作项用 8pt 灰间距切断；
- 退出登录、删除账号等危险动作的按钮文字直接标红警告，与普通选项视觉区分；
- 选项一般 3–6 个，超出改为独立选择页；不承载输入框与长图文。

### 3. Tour 漫游式引导

- 适用新功能上线、首次使用：背景挖空打聚光灯（高亮目标元素、其余压暗），气泡一步步带点讲解；
- 必须含步骤进度（1/3 → 2/3 → 3/3）、上一步/下一步/跳过出口；聚光灯跟随当前目标平滑移动；
- 可手动关闭，不强制打断正在进行的任务；同一用户不重复骚扰，记录已读状态；
- 每个气泡只讲一个动作要点，文案短直，避免大段说明压住目标元素。

### 4. Inline Alert 行内校验

- 表单字段错误紧跟对应输入框下方红字，就近定位，不打断整表提交；
- **死规矩：绝不允许像 Toast 一样几秒自动消失**；必须等用户真正把错误改对（校验通过）后才消失，并切换为成功态对勾；
- 错误文案说清问题与改法（“请输入 11 位手机号”），不写笼统的“格式错误”；
- 校验时机：失焦即时单字段校验，提交时全量复核；多个字段错误时按顺序聚焦第一个错误项。

### 5. Lightbox 媒体灯箱

- 点开缩略图后进入全黑背景全屏预览，查看大图/视频；支持滚轮/双指缩放、左右切换、关闭出口；
- 遮罩与操作图标自动隐藏，点击空白处或关闭按钮退出；
- 加载中给占位骨架，加载失败给重试出口；不把灯箱做成需要保留页面上下文的图文混排页。

### 6. 浮层组件全景分类（选型速查）

| 类别 | 组件 |
| --- | --- |
| 对话确认 | Modal、Popconfirm、AlertDialog |
| 面板承载 | Drawer、Bottom Sheet、ActionSheet |
| 轻提示 | Toast、Message、Notification、Snackbar |
| 悬浮定位 | Tooltip、Popover、Dropdown |
| 引导与预览 | Loading、Tour、Lightbox |
| 校验提示 | Alert、Inline Alert |

## 六、复合组件规约

### 1. DataGrid 表格

**列对齐三铁律**：文本列左对齐（名称、标题、描述、状态）；数值列右对齐（金额、数量、百分比、时间戳，保证个十百千位垂直对齐）；操作与定宽标记居中（复选框、单图标、固定字数短状态）。

- 固定列显式声明固定像素宽度（操作列 `width: 120px`），配微阴影指示横滚切分；小视口先保证主键识别列与操作列可见，次要字段响应式断点隐藏，严禁半截遮挡且无法横滚。
- 超宽表格包裹在自身容器内滚动，**严禁导致整个浏览器主页面出现横向滚动条**。
- 操作列按钮用 ghost/link 纯文本变体；超过 3 个操作时展示最高频 2 个，其余进 `...` 更多菜单。

### 2. FilterPanel 三态

| 筛选项数量 | 推荐形态 | 交互模式 | 场景 |
| --- | --- | --- | --- |
| 轻量 1–3 项 | 单行内联筛选 Inline Bar | 搜索框 + 1–2 核心下拉同行，右侧刷新/导出 | 高频查询、选项极少、垂直空间敏感 |
| 中量 4–8 项 | 折叠展开面板 Expandable | 默认露一行（主搜索 + 2 常用项 + 展开筛选），展开后第二行 + 查询/重置 | 标准后台列表、CRM、财务流水 |
| 重度 9+ 项 | 侧边高级筛选抽屉 Filter Drawer | 主页仅留搜索框 + 漏斗图标，右侧抽屉分组陈列 | 数据仓库、选品库、多维分析 |

### 3. DescriptionGrid 描述列表

2–3 列自适应栅格；Label 用 `text-secondary`，Value 用 `text-primary font-medium`。详情信息按亲密度四层级区隔：
1. 不通栏分割线（同模块内逻辑换行）；
2. 通栏分割线（同卡片内不同功能小段）；
3. 独立白底卡片（独立业务维度：基本信息/结算账户/权限配置）；
4. Tabs 标签页（体量庞大、互不依赖的平级大型模块）。

### 4. BulkActionBar 批量操作浮动条

- 常态隐藏；勾选 ≥1 行时轻量过渡从页面/表格底部滑出；
- 三要素齐备：明确数量告知（“已选择 8 项数据”）、批量行动点（批量导出/分配；批量删除用标红危险按钮触发确认弹窗）、一键反选与清空。

### 5. 导入导出状态机

```text
准备导入 Ready → 本地校验 Validating →（格式/大小错误）校验拦截 ValidationError（可重选）
→ 服务端处理 Processing（进度条，不可随意中断）
→ 成功 Success（绿标 + 新增/更新条数 + 查看数据）｜失败/部分失败 Error（原因清单 + 错误行 Excel 下载 + 重新上传）
```

## 七、导航模式选型

| 导航模式 | 适用环境 | 约束 |
| --- | --- | --- |
| 侧边导航 SideNav | 宽屏后台子系统主导航 | 一级分组 + 二级条目；当前项高亮；窄屏收进抽屉 |
| 顶部切换栏 Tabs / Segmented | 单模块平级视角切换 | 2–4 项分段控制器；5+ 长分类横滑 Tabs，选中项自动居中，两端渐变蒙层暗示可滑 |
| 标签栏 TabBar / BottomNav | 窄屏一级核心业务空间 | 严格 3–5 槽位；图标上文字下，文字 ≤4 汉字；徽标锚定右上角、向左单向膨胀、99+ 收敛；进入二三级下钻页隐藏 |
| 栈式层级下钻 | 列表点条目进入详情 | 新页面右滑入（Push），左滑退回；返回保留滚动位置与筛选状态 |
| 浮动半屏抽屉 | 临时支线任务（筛选、分享、规格选择） | 见第三节底部抽屉规约 |

**顶部导航范式差异**：宽屏 Web 标题可居中或居左；窄屏 iOS NavigationBar 44pt 标题居中 17pt Semibold，大标题 34pt Bold 折叠；Android TopAppBar 56/64dp 标题居左 20sp，右侧三点溢出菜单。

### 侧边导航条目整理细则（入口多但不删功能）

侧边栏条目过多时，优先分组与调主次，而不是砍功能；反面教材：二十多个入口一长列平铺，每项一样大一样亮，选中项仅字粗一点，眼睛不知先看哪。

1. **按场景分组**：常用操作一组、业务对象一组、内容/资料一组；组与组之间拉开纵向间距并加小标题；分割线可保留但用淡微边框，只用来分大块，不逐条画线。
2. **当前位置做明显**：选中项垫一块颜色明显的底块（品牌浅底或中性深底）；其余条目文字暗一档，但对比度仍达 WCAG AA，不能灰到看不清。禁止只靠字重加粗表示选中。
3. **低频入口固定底部**：设置、帮助、账户等平时少点、但要用时必须马上找到的条目，固定在侧栏底部；升级/变现入口点击少但属收入来源，可往下放，不能藏进二级菜单或抽屉。
4. **头尾固定、中间滚动**：条目实在放不下时，顶部品牌/搜索区与底部账户/设置区固定，中间列表独立滚动；条目位置保持稳定，用户靠位置找入口，不随使用频次或版本随机重排。

## 八、组件反模式红线

- 严禁无语义彩虹配色；`danger`/`destructive` 只留给严重错误、阻断、扣款，普通未完成用 info/warning；
- 严禁密集表格中使用刺眼纯深色底标签（坚守浅底深字法则）；
- 严禁表单弹窗点击遮罩静默关闭；
- 审批页严禁主动视觉诱导（“通过”亮绿主按钮、“驳回”灰按钮），双方次级样式保持中立；
- 阴影被父级 overflow 截断成一条黑线时，按基石第五节补余量或降级微边框；
- 已有成熟组件库（shadcn/ui、antd、Radix 等）时，严禁用原生 div 从零手搓弹窗、折叠面板、复杂拖拽与树控件；
- 可逆操作严禁先弹确认框打扰用户，应直接执行 + Snackbar 撤销；
- 行内校验红字严禁像 Toast 几秒自动消失，必须改对后才消失；
- 删库、注销、巨额扣款等不可逆高危动作严禁用 Popconfirm 或可点遮罩关闭的普通 Modal，必须上锁死阻断的 AlertDialog；
- ActionSheet 严禁省略最底部独立分组的「取消」行。

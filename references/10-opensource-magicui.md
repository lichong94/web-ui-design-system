## 定位

面向设计工程师的 UI 库，提供可复制粘贴进应用的动画组件与交互特效，免费、开源。与通用表单/表格组件库不同，Magic UI 偏重“氛围感动效”：滚动动画、动态展示、特效区块等。

## 核心特点（来自仓库元数据与 README）

- 复制粘贴式取用组件，与 shadcn/ui 模式接近。
- 基于 Framer Motion 实现动效，配合 Tailwind CSS。
- 适合在官网首页、产品展示页中快速加入精致动画与视觉特效。

## 适用场景

- 产品官网、落地页首页需要滚动/入场动画、特效组件时。
- 在已有 React + Tailwind + shadcn 项目中补充动效区块。

## 使用要点

- 文档站点：https://magicui.design/docs ，按文档把对应组件代码复制进项目。
- 贡献方式见仓库 contributing guide；社区交流见官方 Discord。

## 注意事项

- 属 React 技术栈；Vue、PHP 传统页面不能直接安装使用。
- README 正文较简略，具体组件清单、参数与示例以官方文档站点为准。
- 星标为检索时点近似值，会随时间变动。

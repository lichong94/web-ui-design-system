# 05 交付前自查门禁清单

人工验收或 AI 生成代码后的自我走查，先核对通用基线，再按目标场景核对附加项。全部通过后方可交付。规则原理见 01–04 篇；可先用 `scripts/audit_web_design.py` 做正则初筛，正则检查不能替代完整人工走查。

## 目录

- 一、通用基线门禁（所有界面必过）
- 二、宽屏后台 / SaaS 场景附加项
- 三、触屏窄屏 / App / 小程序 / H5 附加项
- 四、桌面 Agent / AI 工作台附加项
- 五、代码复核输出格式与复核方法
- 六、最小交付证明记录

## 一、通用基线门禁（所有界面必过）

| 编号 | 检查维度 | 验收标准 | 判据 |
| :---: | --- | --- | --- |
| G01 | 阴影裁切 | 容器内所有阴影完整展开，无截断 | 带 shadow 元素祖先无 `overflow: hidden/auto`；外周余量 ≥ 模糊半径 + 偏移 + 扩散 |
| G02 | 同心圆角 | 内外圆角平行自然，无挤角缺陷 | 外层圆角 = 内部元素圆角 + 容器内边距 |
| G03 | 0.5px 微边框 | 分割线与卡片边框轻盈细腻，拒绝粗黑 | 半透明 RGBA 色值或物理 0.5px 缩放 |
| G04 | 光学视觉重心 | 图标+文字按钮、弹窗位置重心微调 | 图标不机械死板居中；弹窗垂直偏上（38.2% 黄金分割位） |
| G05 | 去占位废话 | 卡片与表单无占位副标题，说明零赘余 | 标题直抒胸臆，占位符仅留必要格式提示，靠布局传递意图 |
| G06 | 主按钮唯一性 | 一个独立操作区最多 1 个 Primary | 扫描页头、工具栏、弹窗底部，无两个实心深色按钮并列 |
| G07 | 审批中立性 | 严肃责任二选一区域无主操作倾斜 | “通过/驳回”均次级样式，不带偏向性配色诱导 |
| G08 | Badge 浅底深字 | 状态标签浅底搭配深色文字 | 无彩虹配色，遵循六大业务语义映射，必须带业务文案 |
| G09 | 弹窗防手滑丢失 | 表单录入弹窗禁用点击遮罩关闭 | `maskClosable={false}`，脏数据时拦截意外退出 |
| G10 | 高危操作阻力 | 删除/扣款操作具备充分心理阻力 | 标题中立交代对象，描述写清后果与不可逆性，按钮动宾明确（“彻底删除”） |
| G11 | 等宽数字防抖 | 看板、指标卡、表格数值全量等宽 | 声明 `font-variant-numeric: tabular-nums`，消除跳动乱抖 |
| G12 | 防孤字成行 | 关键标题与引导文本行距平衡 | 启用 `text-wrap: balance`，末行无孤单单字 |
| G13 | 出海短词膨胀保护 | 按钮与操作区无写死固定像素宽度 | `flex-1` 弹性或 `min-w + px-4`，多语言下不撑爆卡片 |
| G14 | 多语言音标与 RTL | 变音符号不削顶，阿语用逻辑属性 | 行高 ≥1.5 且无滥用 `overflow: hidden`；RTL 下进度条/数字/电话保持 LTR |
| G15 | 页面默认平 | 常规卡片纯平用微边框切分，阴影只给浮层 | 无滥用 `shadow-lg`/多重发光；全页单一强调色；无意义 eyebrow 全清 |
| G16 | 按钮完整六态 | Default/Hover/Active/Disabled/Loading/Focus 齐全 | 异步按钮转圈 + 锁点击防重复提交；Tab 有清晰 Focus Ring，未裸删 outline |
| G17 | 4px 网格与对称内边距 | 全局间距均为 4 的倍数；嵌套内边距对称 | 排查 `10px/14px` 魔术数，嵌套卡片四边留白均匀 |
| G18 | 去 UX 冗余文案 | 仅留核心标题与键值对；低频说明折叠 | 无营销/轻浮口语及常驻辅助说明；布局自体自解释 |
| G19 | 复用成熟组件库 | 弹窗、下拉、折叠面板等复用成熟库 | 基于 shadcn/ui / antd / Radix 等封装，严禁原生 div 从零拼凑 |
| G20 | 暗色模式字重补偿 | 深色主题字重下调一档 | 500→400、600→500，抵消光晕扩散发胖 |
| G21 | 可逆操作走撤销 | 可反悔的删除/归档/取消直接执行，底部 Snackbar 带「撤销」 | 未用确认框打扰；撤销可真实回滚并给二次反馈 |
| G22 | 高危阻断级别正确 | 不可逆动作上 AlertDialog：锁遮罩、禁 Esc、损失可见 | 未用可点遮罩关闭的普通 Modal 或 Popconfirm 兜底；按钮动词+宾语 |
| G23 | 行内校验不自动消失 | Inline Alert 紧跟输入框，改对后才消失 | 未像 Toast 几秒淡出；错误文案说清问题与改法 |
| G24 | 引导 Tour 可退出 | 聚光灯 + 气泡分步，含步骤进度与跳过/关闭出口 | 不强制打断正在进行的任务；不重复骚扰已读用户 |
| G25 | 媒体灯箱隔离 | Lightbox 全屏黑底预览，支持缩放/切换/关闭 | 未把需保留上下文的图文混排做成灯箱 |
| G26 | 浮层选型匹配 | 按决策树选 Modal/Drawer/BottomSheet/ActionSheet/Page/Snackbar | 未把长表单塞进弹窗、未把轻确认做成整页跳转 |
| G27 | 动效时长达标 | 弹窗/抽屉 0.2–0.3s；微交互 ≤150ms；单段过渡 ≤0.5s | 无过长动画拖慢操作，无瞬时无感过渡 |
| G28 | 动效走合成器属性 | 只改 transform/scale/opacity，不改 top/left/width/margin | 无触发布局重排的动画；长列表滚动不卡 |
| G29 | 缓动自然 | 进场 ease-out 先快后慢；离场更快更轻；同组元素同速同曲线 | 无全程 linear 机器感；无同组速度不一致 |
| G30 | 弹性与缩放边界 | Spring 仅用于点赞/弹窗等趣味位；弹窗 95%→100% 入场，不从 0 放大 | 无大面积过冲回弹晃动；无零尺寸突兀入场 |
| G31 | 动效可降级可控 | 尊重系统减弱动态效果；跑马灯悬停暂停；数字滚动用等宽数字 | 减弱动效时瞬时切换；无限循环内容可悬停停住；数字不抖动 |
| G32 | 加载进度真实绑定 | 进度型动效（数字/进度环/进度条）绑定真实数据源；不可知等待用纯装饰循环 | 无匀速假进度条跑满；装饰型不伪装成进度；百分比不跳变 |
| G33 | 加载态克制可降级 | 启动闪屏 ≤1.5s，动画不拖长真实加载；主题元素与业务相关；低端机关闭融球模糊重特效 | 无长等待转圈无出口；无无关吉祥物堆砌；减弱动效时静态/极简渐变 |
| G34 | 图表聚焦与标注 | 重点系列用品牌深色高亮、其余降浅灰；名称与数值直接标注在图形旁；数值右对齐等宽 | 无全系列彩虹同饱和度；无靠图例来回对照；数值列不左对齐、不抖动 |
| G35 | 演示页一页一观点 | 每页只讲一件事，一句话标题；正文 ≤3 行，配大图/大数字；标题页码配色字体套同一母版 | 无一页堆砌多个结论；无满屏小字；各页标题位置与样式不漂移 |
| G36 | 落地页 Bento 主次 | 全站单一品牌色其余黑白灰；Bento 大小格主次分明，主功能占大格；区块留白 80–120；圆角阴影克制 | 无功能区彩色各一色；无等大卡片平铺；无多重深阴影与拥挤区块 |
| G37 | 侧边栏分组与高亮 | 条目按场景分组带小标题，组间留白、分割线淡；选中项有明显底块，其余文字暗一档但对比度达标 | 无二十多条目等大等亮平铺；无仅加粗表示选中；未选中文字灰到不可读 |
| G38 | 侧边栏低频项与结构 | 设置/帮助/账户固定底部；升级变现入口可下移但不藏起；头尾固定、中间滚动；条目位置稳定不随机重排 | 低频入口找不到；变现入口被藏进二级菜单；中间滚动带走头尾；位置随版本漂移 |
| G39 | 控件微交互可复现 | 点赞/提交/开关/长按写清触发顺序、形变数值、颜色、时长与曲线；粒子/对勾/进度环反馈到位 | 无序列表的变色方块；形变无回弹；反馈元素缺失或乱序 |
| G40 | 提交与长按安全 | 提交加载期锁点击防重；长按确认进度走满才执行、松手倒退归零；不可逆高危仍走阻断弹窗 | 加载中可重复提交扣费；长按松手仍执行；用长按替代高危阻断确认 |
| G41 | 语义控件与键盘可达 | 原生 button/链接优先；Tab 可遍历全部交互项；浮层打开焦点移入并锁定、关闭归还触发元素 | 用 `div onClick` 伪装按钮且无键盘支持；浮层打开后焦点滞留底层；Tab 走不到可点控件 |
| G42 | 可读标签与不只靠颜色 | 无文本图标控件补 `aria-label`；表单 label 关联输入；状态同时有文字/图标，不只红绿 | 图标按钮无名称；输入框无关联标签；成功/失败只靠红绿区分 |
| G43 | ARIA 模式合规 | 菜单/对话框/Tabs/列表框/组合框遵循 WAI-ARIA APG 模式 | 自造菜单或对话框语义，读屏无法传达结构与当前项 |
| G44 | 参考图转设计契约 | 参考屏提炼为页面职责/主操作/状态/响应式规则/拒绝模式；重建到自身组件与 Token | 直接照搬他方品牌、专有文案、图片或精确布局；无契约凭感觉复刻 |
| G45 | 组件拆分与职责 | 单组件 ≤200 行；组合优于配置；取数与展示分离；就近共置类型/Hook/测试 | 超大单体组件；props 钻取超 3 层；展示组件直接耦合数据源 |
| G46 | 四断点响应式验证 | 在 320 / 768 / 1024 / 1440px 逐一走查 | 只在桌面宽度自测；窄屏布局挤压或半截遮挡未发现 |
| G47 | 标题层级与排版 | h1 每页唯一，层级不跳级；标题样式不套给非标题内容 | 跳过层级；按钮/标签/强调值冒充标题 |
| G48 | 运行期无关键告警 | 无控制台报错；读屏可传达页面结构；除已知边界外无 axe 可访问性警告 | 控制台抛错；读屏丢失层级；残留可访问性告警未说明 |

## 二、宽屏后台 / SaaS 场景附加项

| 编号 | 检查维度 | 验收标准 |
| :---: | --- | --- |
| W01 | 单选/开关/下拉选型 | 2–4 项单选平铺，立即生效用开关，>5 项用下拉，无滥用 Select |
| W02 | 表格三向对齐 | 文本居左、数值与时间居右、复选框居中；金额计数列右对齐，数位竖直对齐 |
| W03 | 横向滚动容器隔离 | 超宽表格仅在自身容器内滚动，主页面无横滚；固定列有明确宽度与分割线 |
| W04 | 全状态五态覆盖 | 理想/空/加载/错误/受限五态齐备；空态有原因解释 + 一键创建或清除筛选出口 |
| W05 | 查询分层与防卡死 | 基础筛选平铺 ≤4 个；大数据量/慢查询带查询按钮，禁止每改一字全局转圈 |
| W06 | 时间区间防呆 | 预设 Pills 外露，双日历设最大跨度限制，未来日期禁用，格式统一到秒 |
| W07 | 浮层选型正确 | 详情轻编辑首选抽屉保留上下文；高危删除才用确认弹窗；长表单/向导进独立整页 |
| W08 | 筛选面板形态匹配 | 1–3 项内联栏，4–8 项折叠面板，9+ 项高级筛选抽屉 |
| W09 | 批量操作浮动条 | 未勾选隐藏；勾选后告知数量、批量行动点、一键反选清空；高危批量删除走确认弹窗 |
| W10 | 异常页四要素 | 情境配图、错误代码与定性、大白话原因、至少两个明确出口 |
| W11 | 登录页分栏与表单层级 | 宽屏左右分栏，场景侧无可交互控件；表单输入框/按钮/字体/间距走统一 Token；一屏仅一个实心登录主按钮；错误紧贴输入框行内校验；加载期锁主按钮防重复提交 |
| W12 | 登录页行业视觉克制 | 场景配色与元素贴合业务（医疗/安防/物流/能源等）；不堆砌粒子、霓虹、大面积炫光；留白充足、视觉层级清晰；窄屏场景侧隐藏或收为顶部品牌横幅 |

## 三、触屏窄屏 / App / 小程序 / H5 附加项

| 编号 | 检查维度 | 验收标准 |
| :---: | --- | --- |
| M01 | 底部安全区 | 底部常驻按钮与 TabBar 不被 Home Bar 遮挡；声明 `env(safe-area-inset-bottom)` |
| M02 | 顶部安全区 | 顶部导航栏不侵入刘海、灵动岛与前置摄像头；声明 `env(safe-area-inset-top)` |
| M03 | 最小触控热区 | 可点击项 ≥44×44pt（iOS）/48×48dp（Android）；小图标靠 padding 或伪元素外扩 |
| M04 | 相邻按键间距 | 相邻可操作项留白 ≥8pt，杜绝紧贴连带误触 |
| M05 | 键盘防遮挡 | 聚焦低位输入框时平滑居中滚动至视口，容器预留 ≥300px 垫高缓冲 |
| M06 | 键盘类型精准 | 手机号 tel，验证码 numeric + `one-time-code`，金额 decimal，邮箱 email |
| M07 | 手势冲突保护 | 屏幕左边缘 16pt 范围内无横滑轮播劫持返回；真机边缘滑动测试 |
| M08 | 滚动穿透锁死 | 浮层/抽屉展开时底层页面完全不可滚动；猛滑抽屉底层纹丝不动 |
| M09 | 浮层防误触丢失 | 表单录入类抽屉/对话框禁用点击遮罩关闭 |
| M10 | 同心圆角与微边框 | 满足 $R_{outer}=R_{inner}+Padding$；Retina 0.5px 边框 |
| M11 | 主 CTA 唯一 | 一屏内最多 1 个全宽 Primary 主按钮 |
| M12 | 全屏无多余横滚 | 页面外层 `clientWidth === scrollWidth`，无多余晃动和白边 |
| M13 | 图片长宽比秩序 | 列表图文遵循 1:1、4:3、16:9 三段式裁切；`aspect-ratio` + `object-fit: cover` |
| M14 | 弱网与空态出口 | 空列表与网络失败有明确文案和行动出口；乐观更新 + 失败 Toast 恢复，无死锁 |
| M15 | 出海百分比切割 | 底部操作栏左侧五档定宽（72/43/28/13/0%），右侧 `flex-1` 弹性填满 |
| M16 | 下沉市场降级 | 避免大面积毛玻璃与复杂多重 spring；低端真机实测滑动 60fps 无掉帧卡死 |
| M17 | 触控滑动肉感 | 边界回弹有阻尼，手势 1:1 跟手无延迟；离手动量自然衰减 |
| M18 | 空间选座视角预览 | 选座/订房等空间决策前提供真实视角即时预览，减少抽象网格盲猜 |
| M19 | 表格不暴力移植 | 手机端复杂表格转纵向结构化卡片流，仅保留主键与状态 |
| M20 | 单屏表单轻量化 | 单屏字段 ≤5 项，超出分步向导或分组卡片；失焦即时校验 |
| M21 | Bottom Sheet 分档吸附 | 折叠/半开/全屏三档阻尼吸附；高度按 30%/60%/83% 三分屏，不写死像素；顶部拖拽手柄 |
| M22 | ActionSheet 取消分组 | 底部动作面板最底部有独立分组「取消」行；退出登录等危险项文字标红 |

## 四、桌面 Agent / AI 工作台附加项

| 编号 | 检查维度 | 验收标准 |
| :---: | --- | --- |
| D01 | 阴影裁切审计 | `clip-audit.js` 输出 `cut === 0`；默认态/hover 态/展开态/落点态全覆盖 |
| D02 | 窗口原生控制 | 最小化/最大化/恢复/关闭在 Win/macOS 正常响应，热区与原生一致 |
| D03 | 拖拽区隔离 | `-webkit-app-region: drag` 与 `no-drag` 控件区完全隔离，控件位置不触发整窗移动 |
| D04 | 透明无边框边缘 | 四角圆角无黑白杂色底边，透明区域正确透视桌面背景，无点击穿透漏洞 |
| D05 | 图标多尺度 | 16/24/32px 任务栏与 256px+ 大图清晰可辨，轮廓平滑无直角白边 |
| D06 | CJK 安全发送 | 拼音选词阶段 Enter 不误发消息；选词完成后正常 Enter 发送畅通 |
| D07 | 输入框自适应增高 | 连续 10+ 行/粘贴长文本平滑扩展；达 max-height 锁定转内部滚动；局部隐藏滚动条但保留滚轮/选中/键盘导航 |
| D08 | 弹窗滚动槽位防抖 | 开关浮层背景页面无横向突跳；`scrollbar-gutter: stable` 槽位稳定 |
| D09 | 流式视口跟随 | 高速吐字时上滑翻阅立即锁定不被拽回底部；提供“回到底部”悬浮入口 |
| D10 | 状态真实对应 | 运行指示、排队位次、步骤打勾来自实际事件，无静态定时器假冒成功 |

## 五、代码复核输出格式与复核方法

### 1. 复核意见用三列表格

审查 UI 代码时，每个问题一行，输出 `Before / After / Why` 三列 Markdown 表格；不要用“Before: … After: …”分行罗列。Why 列简述取舍理由。

| Before | After | Why |
| --- | --- | --- |
| `transition: all 300ms` | `transition: transform 200ms var(--ease-out)` | 指定明确属性，避免 `all` 引发无谓重排 |
| `transform: scale(0)` | `transform: scale(0.95); opacity: 0` | 现实中物体不从无到有，零尺寸入场突兀 |
| 下拉用 `ease-in` | 改 `ease-out` 自定义曲线 | `ease-in` 起步慢显迟钝 |
| 按钮无 `:active` | `:active { transform: scale(0.97) }` | 按压需即时实感反馈 |
| Popover `transform-origin: center` | `transform-origin: var(--transform-origin)` | 从触发点展开；Modal 例外保持居中 |

### 2. 复核时机与手段

- **次日新鲜眼光复查**：开发当下看不出的瑕疵，隔一段时间以新视角复查更易发现。
- **慢动作 / 逐帧检查**：把动效放慢 2–5 倍或用浏览器动画面板逐帧，检查颜色过渡是否平滑、缓动起止是否干脆、原点是否正确、多属性（透明度/位移/颜色）是否同步。
- **真机测手势**：抽屉、滑动手势等触控交互必须在真机验证；模拟器可作替代，真实硬件优先。
- 可复用项目自身的测试、类型检查与 lint 命令；不为校验临时引入框架或工具链，跑不了的检查项需在交付记录中如实说明。

## 六、最小交付证明记录

每次完成 UI 改动交付时，建议记录：
1. **运行环境**：操作系统版本、运行时（Electron / Tauri / 浏览器）、DPI 缩放比；
2. **状态覆盖**：默认态、Hover 态、展开态、长内容溢出态的截图或录屏证据；
3. **可达与断点证据**：Tab 键盘遍历轨迹、读屏播报结构、320 / 768 / 1024 / 1440px 四断点走查记录；
4. **自动化审计回执**：Python 扫描脚本退出码与违规清单；桌面端 `clip-audit.js` 的 `{ ok: true, cut: 0 }` 证据；
5. **已知未覆盖边界**：受限于测试环境（如仅 Windows 验证、macOS 待测、未跑 axe）如实说明。
